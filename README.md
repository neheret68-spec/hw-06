# hw-06  Лабораторна робота 6

Проєкт виконано для лабораторної роботи 6: застосування JavaScript для створення динамічних вебсторінок.

Використано попередній проєкт з ЛР1–ЛР5. Додано слайдер Swiper.js, скрипт обробки форми без перезавантаження сторінки, збереження масиву відправлених даних у localStorage, модальне вікно з відкриттям/закриттям кнопкою, кліком по фону та клавішею Esc, а також кнопку розгортання і згортання текстового блоку.

JavaScript розділено на окремі файли: `mobile-menu.js` для мобільного меню та `js/app.js` для інтерактивних елементів ЛР6.
